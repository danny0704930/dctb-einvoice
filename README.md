# DCTB e-Invoice Customer Frontend

Public customer form for:

```text
https://einvoice.dctb.my/
```

This repo is deployed as a static Vercel site. The live form submits to the
Google Apps Script URL configured in `shared.js`.

Important files:

```text
index.html
style.css
shared.js
customer.js
assets/
vercel.json
```
